The funniest one line a talking elevator could say, at most 120 characters,
written in the elevator's own voice — an entry for make.fun's
[What the Elevator Would Say](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958) bounty ($2, winner takes all).

## Run it

```sh
python3 main.py
```

`main.py` scores 10 fresh candidate lines against the judge's brief
(voice first, then first-read turn, elevator-specific job, tightness,
freshness), picks the highest-scoring one, and writes exactly that line to
`/output/entry.txt`.
